# Sécurité de Winzlee

Merci de contribuer à la sécurité de Winzlee.

**Ne publiez pas de vulnérabilités exploitables, de mots de passe, de tokens ni de fichiers personnels dans les issues publiques.**

Pour signaler une vulnérabilité en privé, privilégiez la fonctionnalité **« Report a vulnerability »** de l'onglet *Security* de ce dépôt, si elle est activée. Sinon, contactez le mainteneur via les coordonnées publiques de son profil GitHub [KylianProvot](https://github.com/KylianProvot), sans divulguer de détails sensibles dans une issue.

Les versions en prépublication sont destinées aux tests. Pour les problèmes non sensibles (conversion, interface, ergonomie), utilisez les [issues GitHub](https://github.com/KylianProvot/Winzlee-Public/issues).

Winzlee est basé sur [Filee](https://github.com/KnifeLemon/Filee) ; les avis concernant Filee lui-même doivent être adressés au projet amont.
